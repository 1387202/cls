班级助手

班主任 + 数学老师的随身工作台
成绩分析 · 临界生 · 错题归因 · 重点关注 · 一键报告

🎁这是给你的

这个工具帮你把班上的成绩、错题、考勤、积分管起来，并且数据只存在你自己的手机/电脑里，不上传任何服务器。不用注册、不用登录。

它是一个完整的小软件，不需要安装、不需要下载。打开下面的网址就能用。

🚪两个入口

我把两个版本都放在这里，你按设备选：

📱
手机上用这个 打开手机版 → 班级助手
界面是为手机重新做的，底部有 5 个标签，适合随手记、考试后看名单。
💻
电脑上用这个 打开电脑版 → 班级教学仪表盘
屏幕大，适合导成绩、看表格、批量出报告、打印。
两个版本数据是各存各的，需要互通时用「导出加密备份 / 导入备份」搬运，见第 3 节。
两边用的是同一套统计口径和同一套加密格式，备份文件可以互相导入。

🔧另外三个小工具（顺手做的）

除了班级管理，还做了一个 PDF 转 Word 的小工具，处理卷子、资料时能用上。

📄
PDF 转 Word（电脑版，推荐） 打开 PDF 转 Word →
把 PDF 里的文字提取出来，导出成 Word 可以编辑的格式。支持一次拖入多个 PDF 合并处理，也能直接设排版选项。
📱
PDF 转 Word（手机版） 打开手机版 →
手机上用这个，打开的更快（不会一开始就下载 1 MB 多的解析库）。功能一样。
为什么推荐用这个而不是网上的转换网站？
网上的免费转换站都要把你的文件上传到他们的服务器。卷子里有学生姓名、班级、分数，不该随便传。
这个工具全程在你自己的设备上处理，不联网、不上传，可以放心用。
效果说明（先说清楚，免得期待落空）：
  • 文字版 PDF（Word/WPS 导出的、网上下的真题）→ 效果很好，文字、标点、数学符号（√ − ∠ ² ）都能提出来
  • 扫描件 / 拍照的 PDF（整页是图片）→ 提不出文字，这种情况要用带 OCR 的软件（WPS 有）
  • 复杂公式→ 可能变形（分数挤成一行、根号丢失），建议提取后在 Word 里重打
  • 表格→ 文字会提出来，但合并单元格和边框会丢，需要自己重排
其实还有个更省事的办法：直接用 Word 或 WPS 打开 PDF 文件，它会问你要不要转成可编辑文档，点「是」就行。 不花钱、还原度比本工具好、也不用装东西。本工具的优势是完全本地不上传，以及能一次批量处理多个 PDF。
🧩
数学题按知识点分组 打开数学题分组 →
把一份卷子或一堆题目粘进去，自动按知识点归类。做专题复习、错题重练、分层作业、检查组卷覆盖时很好用。
数学题分组是「关键词匹配」，不是人工智能 —— 先说清楚：
  • 它认识的是题目里出现的字词：看到「二次函数」「抛物线」「顶点」就归到二次函数，看到「不等式」「解集」就归到不等式
  • 题目里关键字词明确的判得准。实测 27 道中考风格题：27 题全部归类，24 题判断明确，只有 4 题需要人工核对
  • 题目绕弯说的（如「某商品两次降价求百分率」）可能判错，工具会专门列出来让你手动改
  • 每题都会显示命中了哪些词，方便你核对；不确定的题点「换个类别」就能改
  • 页面底部可以自己增删关键词，用得越久越贴合你们教材的说法

1第一次打开（3 步）

1
用浏览器打开上面的网址 iPhone 一定用 Safari；安卓用 Chrome 或 Edge。
别在微信里点开——微信会把网页放进它内置的浏览器，加到主屏幕和数据保存都会出问题。
2
添加到主屏幕（重要） iPhone：点底部中间的 分享按钮（方框加箭头）→ 往下滑找到「添加到主屏幕」→ 添加。
安卓 Chrome：点右上角 ⋮ → 「添加到主屏幕」。
3
从桌面图标打开，设一个密码 至少 4 位。这个密码用来加密数据，只存在你设备上，别人看不到。
为什么要「添加到主屏幕」？加到主屏后是一个独立的应用，全屏没有地址栏，也不会被浏览器当成普通网页清理掉——数据保存更稳。
请牢记这个密码。它是解密数据的唯一钥匙，忘了就打不开数据了，没有任何后门。建议同时导出一份加密备份（见第 3 节）。

2日常怎么用（4 个动作）

第一次用先点「导学生名单」，从 Excel 里框选名单复制，粘贴进去就行，它会自动认列名。

①
导名单（只做一次） 学生档案 → 导入学生信息表 → 从 Excel 粘贴。学号、姓名、性别、生日、家长电话，有几列认几列。
②
每次考完试：导成绩 顶部「＋ 新建考试」→ 成绩页「录入」→「整列粘贴」，把 Excel 里的分数一列列贴进来。也可以点格子手输。
③
想深挖数学：登记题号表 成绩页 →「设置」→ 题号表，每行写 题号,满分,知识板块,说明。登记后就能自动算出每题难度 P、区分度 D，还有知识板块掌握度热力图——哪个板块全班最弱一眼就看到。
④
每次考完后看三样东西 重点关注哪些学生成绩在下滑 + 有其它信号，决定找谁谈话
临界生离目标线差几分的踩线生
教学 → 题目 P/D得分率最低的 5 题，按这个顺序讲评
最后去「教学 → 试卷报告」一键生成可打印的分析报告。
错题本建议让学生自己登记（或你抽空录）：关键不是记了多少题，而是错因结构的变化。工具会画出「错因随时间迁移」曲线——如果「概念不清」在减少、「计算失误」在增加，说明理解已经过关，剩下是熟练度问题，这是很典型的进步信号。

3两台设备怎么互通（电脑 ⇄ 手机）

因为数据是各存各的（这也是最安全的做法），电脑和手机之间靠加密备份文件搬运：

步骤操作
电脑 → 手机电脑上「设置/我的 → 备份」→ 导出加密备份，得到一个 .cls.json 文件 → 用微信发给自己 → 手机上打开工具 →「导入备份」→ 选这个文件 → 输入备份密码
手机 → 电脑反过来做一次即可（手机上导出，微信发给自己，电脑上导入）
注意方向：导入会覆盖当前设备的数据。建议固定用一台设备做「主设备」录入，另一台只是查看；或者每次同步前先在两台都导出一份，免得覆盖错。
备份密码可以和登录密码不一样，但一定要记住。备份文件是加密的，别人拿到也打不开。

4遇到问题怎么办

现象怎么处理
在微信里点开，界面怪怪的 / 数据存不住微信内置浏览器有限制。点右上角「⋯」→「在浏览器打开」，或者直接复制网址到 Safari / Chrome 打开。
弹红色提示条「当前无法保存数据」先导出加密备份保住数据，再换浏览器重新打开、导入备份。
弹「本地存储不可用」数据没丢，只是这个浏览器不让存。换 Safari / Chrome 重新打开。
如果是无痕模式，换成普通窗口。
iPhone 上加不了主屏幕确认是用 Safari 打开的（Chrome 在 iOS 上不支持加主屏）。分享按钮是底部中间那个方框+向上箭头。
打不开 / 白屏检查网址有没有输错；或者换个网络试试。还不行就告诉我。
换手机 / 换电脑了重新打开网址 → 导入之前导出的加密备份。见第 3 节。

5关于隐私（可以放心）

数据存在哪
只存在你自己的手机/电脑里，加密保存（AES-256-GCM）。不上传任何服务器、不需要联网。
我能看到吗
看不到。密码只在你手上，没有后门。
不收集什么
身份证号、人脸指纹、家庭住址、家庭收入——这些都不要填，工具也不需要。
为什么不提供云同步
学生信息属于敏感个人信息，把姓名、成绩、家长电话上传到服务器有合规风险。本地保存反而最省心。
排名能公开吗
不能。《未成年人学校保护规定》明确教师不得公开学生考试成绩和排名。所以「重点关注」「临界生」这些名单是给你自己看的内部材料，别发到班级群或家长群，也别投屏。
家长会能发什么
「学生成长报告」是一人一页的，只发给对应家长本人，不要把全班的报告打包发群里。

📌三个最重要的提醒

1
每周导出一次加密备份工具超过 7 天没备份会提醒你。清理浏览器数据、卸载浏览器、换手机都会让数据消失，有备份就不怕。
2
密码千万别忘忘了解不开，没有找回功能。
3
学生毕业或你不带这个班了到「设置 → 数据管理」执行一次「彻底删除全部数据」，并删掉所有备份文件。这是《个人信息保护法》要求的最小必要原则。

💡几个好用小功能

统计口径能改
及格线/优秀线/低分线默认 60%/85%/40%，但这是教研上的常见口径，不是广州市统一规定。按你们学校的标准在「设置 → 阈值」里改。
任教科目可切换
工具是跨年级通用的。七年级/八年级/九年级的科目表和知识板块能一键套用，任教科目点科目名就能切换。
期中期末一键出报告
「教学 → 试卷报告」出班级分析报告（含自动生成的讲评顺序建议）；学生档案里点右上角出个人成长报告。
家长沟通稿
学生档案 →「沟通」→ 自动生成一段话术（含成绩变化、作业、错因），改一改直接复制到微信。
评语草稿
学生档案 →「生成草稿」→ 根据这个学生的数据自动写一段期末评语，你改一改就能用。
先看示例数据
第一次打开可以点「载入示例数据」（42 名虚构学生、3 次考试），先把各个界面摸熟，再清掉导自己的。清掉在「设置 → 数据管理」。
